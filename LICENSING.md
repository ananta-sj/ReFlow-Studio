## Source accompanying application downloads
For an official executable download, obtain its matching source archive from
the same GitHub release, using the commit/run identity recorded in its notes and
build manifest. Source includes the application and packaging/build scripts.
A different branch tip may not match the downloaded executable.

Repository: https://github.com/ananta-sj/ReFlow-Studio

## Reuse and contributions
Contributions to the original project code are accepted under AGPL-3.0-only
unless an explicitly agreed arrangement says otherwise. Contributors retain
copyright in their contributions and must have the rights to submit them.

VoiceStudio's AGPL-covered code may be evaluated for compatible reuse with its
notices retained. This licence decision does not import that code or approve
any particular integration. Separately licensed components need individual
compatibility and distribution assessment.

## Decision record
The owner delegated the choice on November 18, 2026. AGPL-3.0-only was selected
to keep covered distributed derivatives and modified network services subject
to its source-availability conditions, and to support evaluation of AGPL-based
implementations such as VoiceStudio. See the licence for the actual conditions.
