# ReFlow Studio roadmap

Our focus is to strengthen the existing application before expanding its capabilities. Work progresses through testing and review; these are development priorities, not promised release dates.

| Phase | Focus |
| --- | --- |
| Issue discovery | Locate and reproduce problems across the existing application and workflows. |
| Interactive testing | Test the real desktop experience, including navigation, settings, accessibility and everyday actions. |
| Fixes and polish | Resolve confirmed defects, improve usability and verify that existing features continue to work. |
| Security review | Review dependencies, data handling and application boundaries; verify fixes before moving forward. |
| Pipeline reliability | Improve processing, progress reporting, recovery and consistent end-to-end results. |
| Dubbing quality | Improve translation, pronunciation, delivery, timing and preservation of background audio. |
| Multi-character dubbing | Strengthen speaker identification, voice consistency and natural conversations. |
| Longer media and batches | Validate complete episodes, longer videos and queued workloads. |
| Release preparation | Check platform behaviour, documentation and packages with volunteer testers. |

Security checks and regression testing continue throughout every phase. Later work depends on evidence from the earlier stages, and priorities may change as testing reveals problems.

Detailed investigations, private test material and internal working notes are maintained separately. Public updates will describe verified improvements and remaining limitations without publishing personal or sensitive operational details.
