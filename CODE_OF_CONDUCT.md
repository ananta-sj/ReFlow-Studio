# ReFlow Studio community code of conduct

Everyone participating in this project's issues, pull requests and other project spaces should be able to contribute without harassment. This applies to maintainers and contributors alike.

## Expected behaviour

- Be respectful, patient and specific. Critique work and evidence rather than a person's identity or ability.
- Welcome people with different backgrounds, languages, experience and accessibility needs.
- Accept reasonable correction, respect privacy, and keep discussions relevant to the project.
- Use permitted media and respect other people's voices, consent and personal information.

Harassment, discrimination, threats, sexualized abuse, doxxing, impersonation, spam and repeated disruptive behaviour are not acceptable. Do not publish private recordings, credentials or personal details to make an argument or report a problem.

## Reporting and moderation

Use GitHub's **Report content** or **Block or report** controls to report abusive content privately through the options GitHub provides. Where available, choose reporting to repository maintainers; otherwise use GitHub Support. See [GitHub's reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Do not create a public issue containing another person's private information. A separate private maintainer contact is not currently advertised.

Maintainers may ask for a change in behaviour, hide or remove content, lock a conversation, or restrict participation, proportionate to the conduct and available evidence. GitHub handles reports submitted to its Support team under its own policies. This volunteer project promises neither continuous moderation nor a response deadline. Do not retaliate against someone making a good-faith report.

Report software vulnerabilities through the separate [security policy](.github/SECURITY.md).
